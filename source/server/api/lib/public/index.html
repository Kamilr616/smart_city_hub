Smart City Hub

Projekt IoT do sterowania i monitorowania urządzeń na makiecie miasta LEGO. Łączy API Node.js/Express i MongoDB, panel React oraz moduły ESP32.

Digital Twin odwzorowuje makietę w przeglądarce. Panel umożliwia sterowanie urządzeniami, podgląd czujników i przeglądanie historii stanów.
