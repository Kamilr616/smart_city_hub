Smart City Hub

An IoT project for controlling and monitoring devices in a LEGO city model. It connects a Node.js/Express API and MongoDB with a React control panel and ESP32 modules.

The Digital Twin brings the model to your browser. The control panel lets you control devices, view sensor readings, and explore device state history.
